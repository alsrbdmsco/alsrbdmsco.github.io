# 1nfra - Network & Server Factory

김민규(Kim Min Gyu)의 포트폴리오 사이트: https://1nfra.kr

정적 HTML/CSS/JS로 만들었고 GitHub Pages로 배포합니다. 빌드 과정은 없습니다.

```
index.html              메인 페이지, 한국어 (Career, Stack, Certifications, Contact)
en/index.html           메인 페이지, 영어 (/en/). 내용을 바꾸면 두 파일을 함께 고칩니다
404.html                404 페이지
assets/css/styles.css   스타일
assets/js/script.js     재직 기간 계산(한/영), 스크롤 등장 효과, 네비 상태
assets/images/          favicon.svg, favicon.ico, apple-touch-icon.png, og-image.png, og-image-en.png
CNAME                   커스텀 도메인 (1nfra.kr)
robots.txt, sitemap.xml
```

로컬 미리보기: `python3 -m http.server 8765` 실행 후 http://localhost:8765/

## 📂 프로젝트 구조

```
/
├── index.html              # 메인 페이지
├── 404.html                # 404 에러 페이지
├── robots.txt              # 검색 엔진 크롤러 설정
├── sitemap.xml             # 사이트맵 (SEO)
├── CNAME                   # 커스텀 도메인 설정
├── README.md               # 프로젝트 문서
└── assets/                 # 정적 리소스
    ├── css/
    │   └── styles.css      # 메인 스타일시트
    ├── js/
    │   └── script.js       # 메인 JavaScript
    └── images/
        └── favicon.ico     # 파비콘
```

## 🛠️ 기술 스택

### Frontend
- **HTML5** - 시맨틱 마크업
- **CSS3** - 커스텀 CSS (프레임워크 없음)
- **JavaScript (ES6+)** - 바닐라 자바스크립트
- **Canvas API** - 파티클 애니메이션

### 호스팅
- **GitHub Pages** - 정적 사이트 호스팅
- **커스텀 도메인** - 1nfra.kr
